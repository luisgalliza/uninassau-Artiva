# 🎤 Artiva — Site de Contratação de Artistas | HTML, CSS e JavaScript 🇧🇷

Este repositório contém o site da **Artiva**, uma empresa **fictícia** de contratação de cantores para eventos, desenvolvido com **HTML, CSS e JavaScript** como **trabalho acadêmico em grupo**.

🔗 **Acesse o site:** [👉 Clique aqui para abrir o site](https://luisgalliza.github.io/uninassau-Artiva/)

## 📌 Objetivo

O objetivo do projeto foi criar um site **bonito, divertido e interativo**, no qual o visitante conhece os artistas, entende como funciona a contratação e encontra os dados de contato da empresa.

O projeto permitiu praticar conceitos como:

- Estrutura de páginas com HTML;
- Estilização e organização visual com CSS;
- Animações e transições;
- Interatividade com JavaScript;
- Navegação entre páginas;
- Design responsivo (adaptação ao celular);
- Organização de arquivos e publicação com GitHub Pages.

## 🌐 Páginas do Site

| Página | Descrição |
|---|---|
| **Início** (`index.html`) | Apresentação da Artiva, atração em destaque e player de música |
| **Artistas** (`Artistas.html`) | Atrações principais e demais artistas do elenco |
| **Como funciona** (`ComoFunciona.html`) | Passo a passo para contratar um artista |
| **Sobre nós** (`SobreNos.html`) | História da empresa, números e valores |

## ✨ Destaques e Interatividade

- 🎆 Fogos de artifício ao passar o mouse sobre **"Seu momento."**;
- 🎭 **Efeito exclusivo para cada artista** ao passar o mouse no card (violões, beijos e guitarras, estrelas, plantas, morcegos, gotas de água, caveiras, lasers e outros);
- 🟢 Barra verde animada sob a logo, inspirada em uma barra de música;
- 🔄 Card de destaque que alterna entre as atrações principais;
- 🎚️ Equalizador animado e link para ouvir uma música no YouTube;
- 🧲 Cards que se inclinam e brilho que acompanha o mouse;
- 🔢 Números que sobem em contagem animada;
- 📍 Rodapé com endereço (link para o Google Maps), contato e direitos autorais.

## 🎨 Identidade Visual

Paleta com **roxo** e **verde** sobre fundo escuro, bordas em degradê nas fotos e layout em grade que se adapta a telas menores.

# 🎤 Artiva — Artist Booking Website | HTML, CSS and JavaScript 🇺🇸

This repository contains the **Artiva** website, a **fictional** company for booking singers for events, built with **HTML, CSS and JavaScript** as a **group academic project**.

🔗 **Visit the website:** [👉 Click here to open the website](https://luisgalliza.github.io/uninassau-Artiva/)

## 📌 Objective

The goal was to create a **beautiful, fun and interactive** website where visitors can meet the artists, understand how booking works and find the company's contact details.

This project helped practice concepts such as:

- Page structure with HTML;
- Styling and visual organization with CSS;
- Animations and transitions;
- Interactivity with JavaScript;
- Navigation between pages;
- Responsive design (mobile adaptation);
- File organization and publishing with GitHub Pages.

## 🌐 Website Pages

| Page | Description |
|---|---|
| **Home** (`index.html`) | Artiva introduction, featured attraction and music player |
| **Artists** (`Artistas.html`) | Main attractions and the rest of the lineup |
| **How it works** (`ComoFunciona.html`) | Step-by-step guide to booking an artist |
| **About us** (`SobreNos.html`) | Company story, numbers and values |

## ✨ Highlights and Interactivity

- 🎆 Fireworks when hovering over **"Seu momento."**;
- 🎭 **A unique effect for each artist** when hovering over their card (guitars, kisses, stars, plants, bats, water drops, skulls, lasers and more);
- 🟢 Animated green bar under the logo, inspired by a music progress bar;
- 🔄 Featured card that rotates between the main attractions;
- 🎚️ Animated equalizer and a link to listen to a song on YouTube;
- 🧲 Tilting cards and a glow that follows the mouse;
- 🔢 Animated counting numbers;
- 📍 Footer with address (Google Maps link), contact and copyright.

## 🎨 Visual Identity

A **purple** and **green** palette over a dark background, gradient borders on photos and a grid layout that adapts to smaller screens.

## 🛠️ Technologies Used

- **HTML5** — page structure;
- **CSS3** — styling, animations and responsiveness;
- **JavaScript** — effects and interactivity;
- **Visual Studio Code** — code editor;
- **Git and GitHub** — version control and hosting;
- **GitHub Pages** — website publishing;
- **Artificial Intelligence** — support for studying and development.

## 🤖 Using Artificial Intelligence as a Learning Tool

In class, we learned the basics of **HTML, CSS and a little JavaScript**, but not everything shown in this project. To deliver the kind of work we had in mind, **beautiful, fun and interactive**, we used **AI as a study tool**.

## 🎓 Academic Context

This project was developed as a **group academic assignment**, focusing on the practical application of **HTML, CSS and JavaScript** and on learning new web development techniques.
